# Screenshots

| File            | Screen                                                  |

They are 1440x810 PNGs, taken on a 1920x1080 window at 150% display scaling and halved, so the text stays sharp. The data is a demo profile filled from the iptv-org catalog (three playlists of public broadcasters and three local custom channels), not a real playlist, so no private stream URL and no personal path is shown.
